# Random Cricket Game (with Random Out)

A simple Python program where the user and the computer play up to 6 balls.
On each ball, both pick a number from 1 to 6 and the totals are added up.
There is a random chance of getting out on every ball, and the out type
(Bowled, Caught, LBW, Run out) is picked randomly.
After the innings, the player with the higher total wins.

Concepts practiced: for loop, range(), random module (randint, choice), list, break, if/elif/else, input()

Note: This is a learning practice project.
